# 多话题讨论闭环验收

验收日期：2026-09-11。环境：macOS、Ego Lite Chromium 浏览器。本地服务 `http://127.0.0.1:8082` / `http://localhost:8082`，两种地址属于不同本机存储域。交付目录为本目录；`web/` 中的另一项个人星球视觉改造不在本次固定版本验收范围内。

## 结果

| 范围 | 验收结果 |
|---|---|
| 蜗牛、丧尸、世界 bug、太阳、猫与画、电车、客厅、食堂、萝卜快跑 | 九题逐一完成浏览、输入、按钮确认结伴、两球对谈、主持人补充、保存；各题在“我的讨论”独立列出 |
| 发言上限 | 本地演示手动最多六次；额外发言操作进入整理阶段；萝卜快跑自动模式实测六次后进入整理 |
| 自由输入 | 默认关系待确认；关系由用户选择；可结伴、解除、纠正，不自动套用示例立场 |
| 草稿与回访 | 未提交输入跨题、刷新恢复；已提交补充与发言轮数恢复；恢复后显示暂停，不自动调用模型 |
| 多份记录 | 蜗牛题保存两份，刷新后仍在；继续探索使用新会话 ID |
| 来源快照 | 模拟同步替换当前材料后，已有记录仍显示保存时的来源文本和发言 |
| 切题竞态 | 模拟模型请求迟到，切题后信号已取消，旧回应未进入新题；返回旧题保留轮数 0，未重复调用 |
| 同步竞态 | 模拟同步请求迟到；切走再回来，旧材料也不能覆盖当前话题 |
| 同步失败 | 受控 502 响应显示失败说明；保留所有策展观点和已保存记录 |
| 来源缓存 | Python 测试验证每题独立缓存，24 小时内不重复请求，每次最多两个搜索；失败第二次请求不发布半份材料 |
| URL | `?topic=<id>` 选择、刷新、浏览器后退和前进均对应正确题目；新访问默认蜗牛 |
| 筛选 | 热榜精选只有客厅、食堂两题，并标注 2026-09-11；无实时热度与自动轮询 |
| 存储失败 | 模拟 quota 错误后出现“仅本页保留”提示；仍可保存本页记录与导出 Markdown；刷新后旧磁盘记录未被覆盖 |
| 删除 | 删除后数量减少；撤销后恢复原记录 |
| PNG | 从真实浏览器下载 900 × 1120 分享卡，检查中文完整；仅包含题目、用户确认文字、日期和产品署名 |
| Markdown | 预览全文后追加修订，下载结果包含修订、原来源链接、完整对谈和 Agent 身份说明 |

## 彩蛋

- 蜗牛：首次结伴后出现；点击产生“财富与持续担忧”假设草稿，不自动提交。
- 丧尸：首次展开追问条件后出现 `03:00:00`；“先准备物资”选项只填主持人输入，提交前补充数为 0，提交后为 1。无真实倒计时。
- 猫与画：第一位发言后入口隐藏；双方首轮结束后显示猫爪；Shift+Tab 可从讨论关闭按钮聚焦彩蛋，Enter 可打开。猫自行逃生的条件明确标为新增假设，提交前不进入对谈。
- 手动暂停时彩蛋 CSS 动画为 `none`；系统减少动态效果时入口仍可操作。没有音频和闪屏。

## 屏幕与操作

- 1440 × 900：白色侧栏精确 300px，独立滚动；星空使用余下宽度。
- 1024 × 768：侧栏 300px，画布 724px；观点、标题、底部操作可见。
- 390 × 844：收起侧栏后宽度 390px，无横向溢出；白色抽屉选择后自动收起；讨论底部面板可阅读、滚动、填写和提交。
- 拖动：桌面真实指针操作使自己的球横向移动 85 个世界坐标单位；随后键盘 Alt+方向键可继续移动。两者均能保留位置。
- 缩放：按钮缩放有效；390px 触控模拟双指缩放由 100% 到约 122%，没有侧栏偏移。
- 讨论镜头：讨论期间隐藏重叠标题；保存的是进入讨论前的画布镜头，关闭或恢复时不会把讨论镜头写成永久首页位置。

手机验证采用 Chromium 视口和触控模拟，不代表已在实体 iPhone／Android 或 Safari 验收。

## 自动测试

```sh
npm test
# 14 passed
python3 -m unittest discover -s tests -p 'test_*.py'
# 7 passed
```

JavaScript 覆盖关系逻辑、九题本地发言、个人输入边界、来源标注、话题草稿与多记录恢复、存储失败、迟到请求令牌、快照剔除 DOM／请求对象、彩蛋严格条件和 Markdown 来源。

Python 覆盖模型适配器、六次上限、当前题目与规则覆盖旧客户端字段、默认萝卜快跑行为、话题校验、缓存隔离、24 小时缓存、同步去重与失败保留。

真实模型成功返回和官方知乎同步成功未纳入本次实测。模型与同步异常用受控响应测试；可用性不冒充真实模型或平台服务验收。策展来源通过已登录页面核对，见 [SOURCES.md](SOURCES.md)。
