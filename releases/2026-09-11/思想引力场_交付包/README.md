# 思想引力场 · 前端交付包

## 内容

- `dist/`：可部署的前端原型源码与构建产物。
- `知乎黑客松_项目记忆_知识输入星球.md`：已确认的知识输入态星球参数与视觉约束。

## 已确认体验

用户输入知识后，输入框轻柔退场，镜头拉远，个人星球进入可拖拽、可缩放的思想世界。世界以干净留白为背景，许多轻盈星球形成松散聚落；用户可搜索、悬停阅读摘要、点击展开详情，并拖动自己的星球靠近其他星球。

## 视觉基线

- 材质：晶莹透亮、冰白边缘、冷白/冰蓝半透明细密粒子、薄纱流动感。
- 输入态：正圆完整稳定；速度 `1.5`、扰动 `1.0`、辉光 `1.0`；内部对向涡流与粒子翻卷。
- 世界态：保持轻盈和生命力，控件收在边缘，视觉重心始终在星球之间的关系。

## 运行

直接部署 `dist/` 目录为静态站点；本地也可通过任意静态文件服务器打开。
