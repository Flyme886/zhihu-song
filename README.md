# 和不同

> 知乎黑客松 2026 校园新锐季参赛项目

**一句话**：你坐在答主的位置上。三个人来问你同一件事，你手里有四张知乎高赞回答做成的卡 —— 卡不够分，你得决定哪句话给谁，哪句话不说。

**记忆点**：同一张卡，三个人三种结果；同一张卡，两个年代两种结果。

## 它做什么

不做判决，不做折中，不做辩论胜负。四步：

1. **配卡** — 每个节点发 4 张卡、来 3 个提问者，你必须弃掉一张。稀缺把问题从「哪张卡最好」换成「这张卡适合谁」。
2. **结算** — 只有三种结果：**生效 / 无效 / 反噬**，没有成功失败。规则完全确定，没有骰子；意外来自提问者藏着的能力缺口，不来自随机数。
3. **卡失效** — 走到下个节点，某张卡会被回调：卡面一个字没改，赞数还在涨，它依赖的条件已经没了。
4. **复盘** — 结束时才展开条件地图，指给你看十年里分水岭扫过了谁、没扫过谁，以及你弃掉的那张卡本来适合谁。

卡面上印的不是结论，是「如果……就……」。卡牌这个格式有个好处：**它逼着你把前提写进一个必填的槽位**。散文可以省掉前提，省掉了还显得更有力 —— 所以高赞回答系统性地省。我们只做了一件事，把它印回卡面上。

## 硬约束

- **引文逐字校验**：`quote ∈ source_text`，不通过直接丢弃，绝不进 UI。禁止润色、禁止省略号拼接不连续片段。
- **条件必须可回溯**：每个条件挂原文出处，UI 标三档来源 —— 答主原文自述 / 人工校验 / AI 推测。最高档是答主自己在回答里写明的适用范围（「前提是……」「只适合……」），可点进原帖核对 —— 不是我们的判断，是他亲口划的边界。**卡面的「如果」那一句，只能来自这一档。**
- **卡是真的，提问者是虚构的**：卡面每句话可点回原帖；三个提问者是我们捏的角色，UI 必须主动说明，不等用户问。类型层用 `is_fictional: true` 强制打标。
- **答主是卡牌设计师，不是卡**：可以说「这张卡在当前版本很弱」，不能说答主错了。
- **运行时 0 次 AI 调用**：3 个议题的数据离线生产 + 人工核验后落库。现场无论多少人把玩都不耗配额。
- **不用「打脸」「幻觉」「落后」**：统一表述为「当年的合理判断」+「后来变化的条件」。答主是知乎的核心资产，不是素材。

## 现在最该做的事

**§14.1 的五条地基验证**，全部纯人工、不需要代码、不需要 API：

1. 一个节点凑得出 4 张「结论各有侧重、可查时间与赞数」的真实高赞回答？
2. **这些回答里含答主自述边界的句式？**（卡面「如果」那一句的唯一来源，不联系任何人）
3. 议题 1 能溯源到 2014~2016 年的拍照搜题争论？
4. 搜索 API 是否返回 `created_at` / 赞数 / 原帖链接？
5. 2021~22 的双减 + 搜题应用整改，能支撑一次「卡失效」回调？

第 1、2 条任一不成立整个方案失效 —— 没有第 2 条就没有卡面。先验证，再写代码。

| 09-16 → 09-18 | 传播冲量 + 打磨 + 演练 |
| 09-19 | 决赛路演 |

只带 2 个节点也要在 09-09 上线。「一局玩下来会不会太长」和「反噬那一下有没有『啊?』」只有真人能回答，而这两个答案都可能要求改流程 —— 拖到最后两天就只能硬扛。

时间富余优先加节点深度，不加议题数量：完成度占 25%，多一个议题是线性收益，早一周的反馈是结构性收益。
