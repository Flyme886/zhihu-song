# 和不同

> 知乎黑客松 2026 校园新锐季参赛项目

**一句话**：把知乎上两篇结论相反的高质量回答，放进同一张条件地图 —— 让你看见它们各自在什么条件下成立，也看见时代如何让分水岭移动。

**记忆点**：改变自己，人在地图上移动；改变时代，分水岭向你移动。

## 它做什么

不做判决，不做折中，不做辩论胜负。做三件事：

1. **个人条件层** — 拖动 4 个滑杆。前 3 次微调只让你逼近分水岭，第 4 次跨过去，结论翻转。没有任何单个条件足以改变结果。
2. **时间层（认知年轮）** — 个人条件完全不动，只拖年份。这次是**分水岭向你移动**。远程办公议题里它在 2022 年还往回退过一段 —— 共识不总是往前走。
3. **人物层** — 地图上的点是真实答主。「最值得认识的异见者，不是离你最远的人，而是只差一点点却走向另一边的人。」

## 硬约束

- **引文逐字校验**：`quote ∈ source_text`，不通过直接丢弃，绝不进 UI。禁止润色、禁止省略号拼接不连续片段。
- **条件必须可回溯**：每个条件挂原文出处，UI 标三档来源 —— 作者确认 / 人工校验 / AI 推测。
- **运行时 0 次 AI 调用**：3 个议题的数据离线生产 + 人工核验后落库。现场无论多少人把玩都不耗配额。
- **不用「打脸」「幻觉」「落后」**：统一表述为「当年的合理判断」+「后来变化的条件」。答主是知乎的核心资产，不是素材。

## 时间线

赛前开发不受限（已确认），所以策略是**早上线**，不是早做完。

| 日期 | 事项 |
| :--- | :--- |
| 08-30 → 09-05 | 地基验证 + 脚手架 |
| 09-06 → 09-09 | 议题 1 闭环并 **上线公开 URL** |
| 09-10 → 09-12 | 首轮用户测试 → 改结构 → 补议题 2、3 |
| 09-13 | 报名截止（务必提前）／官方窗口首日 |
| 09-13 → 09-15 | 提交物料 + 二轮测试 + 剩余功能 |
| 09-16 → 09-18 | 传播冲量 + 打磨 + 演练 |
| 09-19 | 决赛路演 |

只带一个议题也要在 09-09 上线。「用户能不能看懂两种移动的区别」只有真人能回答，而这个答案可能要求改动效甚至改布局 —— 拖到最后两天就只能硬扛。

时间富余不加第 4 个议题：完成度占 25%，多一个议题是线性收益，早一周的反馈是结构性收益。
