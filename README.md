# 思想引力场 · Gravity of Minds

知乎黑客松 2026 校园新锐季参赛项目，赛道：**灵魂匹配局 · 社区 × 社交 × 知乎生态**。

相似的观点结伴，不同的观点对话。用户把自己的想法放入一张安静的画布，拖动观点球与相近观点组成二连球，再携伴碰撞不同看法；AI 协助组织材料与讨论，用户始终可以补充、纠正和确认最后留下的记录。
