# 认知年轮 · Cognitive Rings

> 知乎黑客松 2026 校园新锐季参赛项目

**一句话**：把知乎沉淀 15 年的争论重建成一条「共识演化时间轴」，让用户看清一个议题上的主流判断是如何被推翻的、当年的少数派赢在哪里，以及今天哪些低热度非共识可能是下一个答案。

**不是什么**：不是 AI 问答框，不是知乎版内容总结器。产品没有 Chat 输入框，形态是一个数据可视化控制台。

## 核心机制

1. **共识散点图** — X 轴时间、Y 轴立场光谱、点大小 = 赞数、点颜色 = 事后被验证 / 被证伪 / 未决。「大而红聚在上半区，小而绿散在下半区」这个视觉本身就是论点。
2. **证据可回溯** — 每张卡片的引文必须是知乎原文逐字子串（后端校验），赞数 / 时间 / 认证身份直接取 API 字段，每条都挂可点击原帖链接。模型只负责解释，不负责事实。
3. **条件归因** — 不说「谁错了」，说「哪个变量变了」。2016 年「三元锂五年内无法解决热失控」在当年成立，隐含条件是封装维度不变；2020 年 CTP / 刀片动了这个变量，结论才失效。
4. **今日候选先知 + 时间胶囊** — 用同一套规则从今天的回答里捞出低热度非共识，标注「待验证」，用户可押注并生成可回访 URL。这是对「后见之明偏差」质询的功能性回答。

## 关键约束

- 直答 Agent 100 次/天、热榜 API 100 次/天、搜索类 1000 次/天 → 演示当天按「直答仅 ~20 次可用」设计
- 15 个黄金议题离线预跑入库，命中缓存 0 API 消耗；冷启动推演每次 2 次直答 + ~12 次搜索
- 初审权重：AI 场景价值 40% / 创新度 25% / 完成度 25% / 体验 10%

## 最高优先级风险

整个产品压在一个未验证的假设上：**知乎搜索 API 返回回答时间、赞数、答主认证身份、原帖链接**。缺时间戳则时间轴产品失效，缺赞数则高低赞对比失效。开发头 2 小时必须验证完并决定是否走 Plan B（详见 [PRD.md](PRD.md) 第 11 节）。
