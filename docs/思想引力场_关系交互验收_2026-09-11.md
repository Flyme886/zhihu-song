# 思想引力场：关系交互原型

日期：2026-09-11。基于用户提供的前端交付包，在 `web/` 开发；`releases/` 原包与解压源码保持不变。

## 体验路径

1. 点击“用示例体验”，进入作文反馈议题。
2. 拖动“我”靠近“让反馈来得更及时”，或打开详情后点击“靠近这颗星球”。
3. 查看关系理由，点击“连接这颗星球”。细薄粒子带连接两球；拖动任意一颗球，同伴弹性跟随。左下角支持解除连接。
4. 靠近“别让表达趋于同一种”，出现柔和排斥、相对边缘弧线和分歧理由；用户点击“聊聊这个分歧”才进入讨论。
5. 讨论按“说清楚／问关键／留下来”推进。可以随时补充条件、提前结束或返回画布。补充内容进入后续示例回应和待核实事项。
6. 整理共同点、分歧与待核实问题，允许补充或纠正后确认。保存记录后可从画布回看，刷新会清除。

键盘：Tab 选择球并 Enter 查看；Alt + 方向键移动自己的球或已连接同伴；/ 搜索；Esc 关闭讨论；画布支持缩放与平移。

## 视觉与架构

沿用原 WebGL 粒子渲染器，输入态 1.5 / 1.0 / 1.0 保留。新增 Canvas 2D 关系层，绘制粒子连接、排斥边缘和发言波纹，讨论时发言球内部流速增加。

- `app.js`：入口、场景、相机和输入事件。
- `particles.js`：交付版本原有 WebGL 渲染器，未改动。
- `relations.js`：关系来源、邻近检测、阻尼跟随及排斥几何。
- `relationship-ui.js`：关系操作、讨论与本页记录；通过场景接口驱动视觉。
- `style.css`：保留原材质与色调，新增关系提示、结伴状态和讨论面板；移动端采用底部面板。

距离不判断语义，拖动不改变观点。仅预置示例输入启用预设关系；自定义输入需由用户在详情确认“相近／有分歧／暂不相关”。修改个人观点清除当前连接与已确认关系。即使使用示例输入，也只有指定的作文反馈分歧启用预设讨论，其他关系使用手动讨论。

## 已完成验证

- Node 语法检查与 4 项逻辑测试通过：自由输入关系隔离、邻近候选过滤、跨帧率跟随稳定性、排斥不抢占拖动位置。
- ego-browser 本机真实浏览器验收：进入世界、关系详情、结伴、拖动自己的球后同伴跟随、分歧提示、讨论推进、插入条件、记录确认与回看、解除连接。
- 自定义观点不继承示例关系；手动确认可连接；修改观点后清除旧连接；减少动态效果模式初始暂停。
- 390 × 844 手机尺寸检查：输入页和讨论正文可见，讨论列表独立滚动，无页面横向溢出。
- 修复悬停卡片遮挡右侧球的问题；调整输入卡片避免短屏底部裁切；搜索后进入讨论时保留参与球的可见性。

## 当前边界

这是前端交互原型，不包含实时模型、真实知乎检索、多人在线或后端持久化。预设讨论已标注“非实时 AI”，不宣称语义推理或真实社会互动。页面记录只保存最近一次用户确认的讨论。本机浏览器通过不等同于所有设备的性能验证；尚未上线部署。
