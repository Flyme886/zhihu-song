# 彩色星球、来源卡片与 Agent 对谈

2026-09-11。本记录接续同日关系交互版本，以本记录为最新状态。

## 已实现

- 所有星球共用原始 WebGL 粒子材质与相同 chaos/glow 参数，仅改变 tint、大小与旋转相位。个人星球冰白，五个来源分别为紫、青、金、绿、粉。
- 桌面悬浮、键盘聚焦、触屏首次点按均可打开 9:16 卡片。卡片按可用屏幕高度等比缩放；正文独立滚动；显示真实知乎矢量标识、原答主头像、昵称、签名、原文摘录和原回答链接。头像失败时降级为文字头像。
- 五个来源是用户提供的知乎问题页面材料，采集日 2026-09-11。头像、名称与永久链接在用户打开的 Edge 页面核对；没有接入知乎后台同步。UU酱谈的是另一所学校，卡片单独提醒其适用范围。材料陈述未做独立事实核验。
- Agent × Agent 可以从任何两颗不同星球开始；星球 A/B 分别保持自己的材料视角。支持手动下一轮、自动对谈、暂停、主持人补充、最多六次发言、提前结束、记录与完整发言回看。讨论或关闭时取消后续调度，关闭时忽略尚未完成的模型返回。
- 讨论双方不必反对；不会因为对谈自动建立相似关系。预设关系可纠正，真实分歧仍由用户确认。

## 模型边界

默认演示模式使用 agent-turns.js 的本地预设逻辑，会纳入主持人条件和另一方问题，但不是实时大模型。

server.py 提供 /api/agent/status 与 /api/agent/turn。配置三个 AGENT 环境变量后可开启实时模式；每次调用把发言方材料、对方材料、当前对话、主持人补充传给服务端模型。原文和模型发言在 UI 中区分，不冒充原答主。

没有真实模型凭证，因此仅对本机模拟模型进行适配器测试。未安装知乎 CLI，未配置知乎凭证，未外发消息，未发布网站。

## 验收

- 7 项 Node 逻辑测试通过。
- Python 适配器集成测试通过：未配置返回 503，正常模拟回应 200，超轮次 400，不暴露服务端源码 404；发言方材料和主持人条件传递正确。
- 浏览器检查 1440×900 与 390×844。桌面卡片 306×544，头像成功加载，手机无水平溢出。
- 两颗非用户星球按 A/B/A 次序发言；主持人条件出现在后续回应；自动对谈终止并整理；记录保存、回看保留输入。
- 原始交付包与粒子着色器保持不变。记录仍只保存在本次页面，刷新清除。
