# 截图四项任务的实现与验收

日期：2026-09-11。范围：携伴讨论、可确认的讨论收获、关系建议、首次体验。

## 已实现的行为

| 任务 | 当前行为 |
| --- | --- |
| 同伴参与 | 以“我”为发言方时，独立同伴的完整原文随主张进入模型请求。发言展示同伴增加的理由与原文依据；同伴不能与讨论双方重复。记录保留当时的同伴快照。 |
| 讨论收获 | “结束并整理”根据已完成发言生成新理解、共同点、仍有分歧、待核实问题。各项可编辑，引用可跳到原发言，可选为个人收获后确认保存。没有双方证据时允许没有共同点。 |
| 关系建议 | 提交观点后，每次比较当前话题的前 6 条材料，提炼标题、主张与条件。区分结论接近但理由不同、关切相同但方案或条件不同。AI 建议与用户确认分开，用户可以纠正。 |
| 首次体验 | 无讨论记录时首页主入口为“探索一个问题”，进入蜗牛题；首次成功保存讨论后，邀请回看这次星球记录。已有记录时个人星球成为主入口。 |

原回答正文与富文本保留完整；AI 提炼在独立区域显示，不覆盖来源。历史记录优先显示收获与整理，完整对谈和当时来源可以展开。

## 实现位置

- `web/thought_tasks.py`：任务结构、材料分段编号、原文引证回填与校验。
- `web/server.py`：`/api/thought/analyze`、`/api/discussion/summary`、携伴发言处理。
- `web/thought-client.js`、`web/thought-advice.js`：内容签名缓存、关系建议、修改和取消。
- `web/discussion-summary.js`：整理草稿、编辑、引用跳转。
- `web/session.js`、`web/history.js`：同伴和整理快照、导出与恢复。
- `web/app.js`、`web/relationship-ui.js`、`web/planet-ui.js`、`web/index.html`：入口衔接；与同工作区的界面任务协调完成。

结构化引用使用原文片段编号，由服务端回填；不存在的发言或片段会拒绝。共同点必须引用双方的实际发言。此校验确认出处存在，含义仍需用户审核。失败不切换成预设 AI 结果。
