# 星球输入动画与关系交互修复

本地版本：`web/`，2026-09-11。打开 http://127.0.0.1:8081/#/world/snail 后点击“写下我的想法”。

## 修复内容

- 输入面板重新进入独立的星球形成状态：空稿有可见粒子，输入增加粒子密度，球体持续流动旋转；关闭保留草稿，提交后展开回公共观点画布。
- 将原交付版的粒子带与球壳着色器迁回共享 Three.js 渲染器，替换新版的条纹球面。首页、入星旅程和个人历史仍使用原有场景。
- 靠近尚未确认关系的观点时显示就地选择。确认相近后连接并跟随，确认分歧后出现张力弧并排斥；“暂不相关”退出提示。距离不推断观点是否相同。
- 以距离最近的可交互星球为提示对象，避免较远的旧关系抢走新对象。
- 手机关系面板压缩到画布下方，结伴状态放到上方，保证连续拖动与解除连接按钮可用。

## 验收

- JavaScript：23 / 23；Python 服务：7 / 7。
- 桌面真实浏览器（1200×800）：输入渲染数量从约 17,307 增至 121,119 个粒子；动画时间持续变化；草稿输入和关闭均不增加观点版本，提交后增加一个版本。
- 桌面拖动：连接线有 2,125 个非透明像素，同伴跟随；分歧目标在触碰中移动约 45 CSS 像素；个人球拖动不会进入历史场景。
- 手机视口（390×844、DPR 2）及浏览器触摸事件：连接、跟随、解除、再次靠近、确认分歧和排斥通过。连接线有 1,496 个非透明像素，目标移动约 34 CSS 像素。此为触摸模拟验收。
- 返回首页再回公共话题、刷新：草稿恢复，无额外观点版本。
- 系统减少动态效果：停止旋转，输入仍更新密度，提交可用。
- 验收页面没有 JavaScript 异常；测试使用独立存储前缀。浏览器注入脚本在初始化后移除，避免多次验收互相覆盖存储前缀。

## 回归脚本

```sh
npm --prefix web test
PYTHONPYCACHEPREFIX=/tmp/zhihu-pycache python3 -m unittest discover -s web/tests -p 'test_*.py'
```

浏览器回归在 `web/tests/planet-interactions.browser.mjs`，由 Ego 的 Node.js 环境导入：`verifyFormation(page)`、`verifyRelations(page)`；触摸验收传 `verifyRelations(page,{touch:true})`。先在同一任务空间导航到本地页面，调用前确认视口及触摸设置。每次输入验收创建独立的 `planet-interactions-<timestamp>.` 存储前缀，不依赖清空用户存储。
