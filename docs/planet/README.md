# 我的星球 · 本地交付与验收

2026-09-12 的最新交互与验收见 [停留自动连接与辩论](automatic-encounters-2026-09-12.md)，动效实现见 [星球互动与讨论舞台](celestial-interactions-2026-09-12.md)。以下保留原交付记录。

日期：2026-09-11。开发目录：`web/`。本次交付为可运行的本地前端；保留原生 JavaScript、Python 服务、9 个公共话题和既有关系／讨论逻辑。原始 `releases/` 交付包没有改动。

## 打开与运行

```sh
npm --prefix web run dev
# http://127.0.0.1:8081/#/home
```

Three.js 0.180.0 已随 `web/vendor/three/` 分发；运行页面不依赖 CDN，也不需要先安装 npm 包。Python 服务必须运行，不能双击 HTML 用 `file://` 打开 ES Modules。更改端口或切换 `localhost` / `127.0.0.1` 会形成不同的浏览器存储空间。

首页的“进入我的星球”与球体均可进入。首次约 7 秒，后续约 2.5 秒，可跳过；系统减少动态效果时只做短过渡。三座地标及同名文字按钮进入个人历史。手机使用底部阅读面板。首页保持静音，首次明确点击后按照声音设置启动；右下角可静音和调整总音量、环境、穿越、交互四项设置。

## 已实现

- 单个 Three.js WebGL2 渲染器：远景个人星球、星环、穿云遮罩、地表景观、地标镜头，以及公共观点球渲染适配器。HTML 承担全部文字、按钮和内容阅读。
- 原创远山纹理、实时星球云纹、星环、星点、近景地形。保存观点／讨论后，相应地标区域增加代表光点，每类最多绘制 36 点，完整历史仍可分页查阅。
- `#/home`、`#/world/:topicId`、`#/planet`、`#/planet/:section/:recordId` 导航；浏览器后退和记录详情刷新有效。
- 三类本机历史：正式提交的观点版本、实际参与的案例、明确确认保存的讨论。搜索、按话题筛选、时间排序、8 条分页、详情、Markdown 导出、完整 JSON 备份；讨论删除后可撤销。
- 观点修改追加版本；输入草稿不产生版本。案例材料和讨论保留来源快照，继续讨论会创建新会话，旧记录保持不变。
- 离开公共画布保存位置、缩放和主持人草稿，停止自动对谈；返回后由用户恢复。个人球点击进入星球，超过 5 像素的拖动仍用于关系交互。无个人观点时顶部入口也可进入空星球。
- 三条声音总线（环境、穿越、交互）、总音量、限流、淡入淡出、动态压缩。阅读环境降低约 8 dB；跳过取消穿越声；重新入星清理前次短音；页面隐藏时暂停声音和主动画。
- WebGL 不可用或上下文丢失时切换可操作的静态界面；远山纹理加载失败时使用程序绘制的山脊；话题目录失败／超时后保留历史入口和个人想法输入。

## 存储与接口

保留 `gravity.sessions.v1`，新增 `planetVersion`、`settings`，每个话题新增 `opinions`、`visitedAt`、`sources`。旧版本迁移前把原始 JSON 原样备份到 `gravity.sessions.v1.before-planet`，不修改原始备份。旧输入迁为一个观点版本，缺失时间保留 `null`，界面显示“时间未记录”。存储失败后不覆盖原存储，保留本页编辑结果、显式提示和导出能力。

`SessionStore` 提供观点追加、订阅、设置和 JSON 导出；`history.js` 负责索引、来源快照、查询和路由解析。`planet-ui.js` 组织路由、旅程、焦点和阅读状态；`cosmos.js` 只接收场景、时间、地标和数量；`audio.js` 只接收明确的场景与交互事件。

首次载入首页时不会把尚未初始化的公共画布写入存储。进入与离开讨论时还会等待相机目标落定再保存，避免把讨论特写误存为返回位置。浏览器后台恢复后重置动画时钟，旅程不会跨过隐藏期间。

原始素材及依赖来源见 [素材说明](../../web/assets/planet/README.md)。WebGL2 和音频用户手势行为依据 [Three.js 官方说明](https://threejs.org/docs/pages/WebGLRenderer.html) 与 [MDN Web Audio 实践](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。

## 可复核的验收结果

环境：macOS，Ego Chromium 实际浏览器，GPU 报告为 Apple M5 / ANGLE Metal。移动端为同一桌面浏览器的视口与触摸模拟，不能代表手机硬件表现。浏览器测试使用 `planet-acceptance.` 前缀的隔离存储，未把验收内容写入用户的个人历史。

| 检查 | 结果 |
| --- | --- |
| JavaScript 单元测试 | 20 / 20 通过，包括原关系逻辑、讨论、迁移、版本、来源快照、筛选分页和存储失败 |
| Python 服务测试 | 7 / 7 通过，包括现有 API、话题目录和私有资源不可访问 |
| 首次旅程 | 实际音轨：入星 0.043 秒、星环 3.813 秒、落地 7.013 秒；界面首次完成约 7.04 秒 |
| 重复进入与跳过 | 后续 2.5 秒；20 次连续进出／跳过均到达正确场景，没有 JS 异常 |
| 资源稳定 | 20 次检查中最终版本几何体 26、纹理 1 不增长，每次入星后的短音不超过 4 个，结束后活动音源为 0；不等同于完整 GPU/堆内存分析 |
| 数据与刷新 | UI 提交两次观点、保存一次演示讨论；刷新后版本与来源仍在；初始草稿、输入和相机不会被首页覆盖 |

## 已知限制

- 桌面 60 FPS 目标尚未达到。降低分辨率、关闭星环和关闭部分 CSS 效果未显著改变此次浏览器测得帧率；原因没有完全定位。当前有分辨率与星点密度自动降档，不能据此宣称已经达到 60 FPS。
- 手机只完成模拟视口与触摸验收，尚未在真实 iPhone／Android 硬件上验证稳定 30 FPS、功耗和音频后台策略。
- 音频完成浏览器实际录制、事件同步、电平和接缝检查；没有完成不同耳机／扬声器上的人工听感验收。录音用于进一步确认舒适音量和声场。
- 历史只保存在当前浏览器和当前地址。JSON 为备份导出，本次不新增导入、账号或云同步功能。大量记录仍受 localStorage 容量限制。
- 在线模型与知乎同步沿用原项目配置，本次验收使用本地策展材料与明确标注的演示对谈，未新增账户、调用凭证或公网部署。
